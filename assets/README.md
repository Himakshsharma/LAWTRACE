Put a photo of the Supreme Court of India here as `supreme_court.jpg` (or .png / .webp) to use it as the entrance background.

If no local photo is present, the app loads one from Wikimedia Commons, and if that fails it shows `court_lineart.svg`, a gold line drawing of the building. Use a photo you have the right to use (Wikimedia Commons images are freely licensed; credit the author).
